Présentation du projet

Explorer les biens plus simplement.

Un prototype web immobilier pour organiser la découverte de biens à louer, de biens à vendre et de terrains, avec une interface multilingue.

  • React Router
  • Express
  • MySQL

Ma démarche

Développement agentique avec AI Coding Agents

Je définis les fonctionnalités et les critères d’acceptation, prépare le contexte technique et décompose les évolutions en tâches vérifiables. Je pilote ensuite les AI Coding Agents pour implémenter les interfaces, intégrer les services et résoudre les anomalies. Chaque itération fait l’objet d’une revue de code et d’une validation des parcours ; les propositions générées sont ajustées aux contraintes du projet, avec mise à jour des tests et de la documentation.

Le contexte

Le défi

Rendre lisibles plusieurs catégories de biens et préparer une recherche par ville ou type de bien, sans multiplier les parcours de navigation.

La réalisation

La solution

Une interface React avec React Router, des pages dédiées aux catégories et une couche de traduction en français, arabe et anglais. Le projet comprend également une API Express et un schéma MySQL.

  • Rubriques location, vente et terrains
  • Champs de recherche par ville et type de bien
  • Navigation français / arabe / anglais
  • Structure de pages de biens et d’authentification

Ce que le projet apporte

Le prototype pose les bases d’un parcours de recherche immobilière. Les annonces d’exemple visibles dans la capture servent à illustrer la structure ; elles ne constituent pas un catalogue de biens réels.
